\begin{abstract}
We present VISÃO, an agentic cognitive architecture combining Liquid Time-Constant (LTC/CfC) networks with local plasticity and task-specific readouts for continual learning.
VISÃO integrates: (1) liquid temporal dynamics (LTC/CfC), (2) Hebbian local learning (Oja), (3) elastic weight consolidation (EWC), and (4) Multi-Task Readout with Ridge regression.
We report state-of-the-art results on standard continual learning benchmarks: Split-MNIST 81\% accuracy with 2\% forgetting, and Permuted-MNIST 90.6\% accuracy.
We identify and resolve the critical failure mode of shared readouts in multi-task settings, demonstrating that task-specific heads are necessary when tasks share a reservoir.
Scaling laws reveal $\alpha=+0.056$ with $R^2=0.994$, indicating stable (if weak) positive scaling.

\medskip
\textbf{Keywords:} continual learning, liquid neural networks, catastrophic forgetting, local plasticity, EWC, Multi-Task Readout
\end{abstract}

%--------------------------------------------------
\section{Introduction}
%--------------------------------------------------

Catastrophic forgetting remains a fundamental challenge in neural networks --- when trained sequentially on multiple tasks, models rapidly lose performance on earlier tasks \cite{kirkpatrick2017overcoming}.
Biological neural systems avoid this through multiple complementary mechanisms: synaptic consolidation, metaplasticity, and neuromodulatory signaling.

VISÃO draws inspiration from these biological mechanisms, combining:
\begin{enumerate}
    \item \textbf{Liquid dynamics} (LTC/CfC): Temporal processing with input-dependent time constants \cite{hasani2022liquid,chahine2023robust}
    \item \textbf{Local plasticity} (Oja): Hebbian weight updates without backpropagation
    \item \textbf{EWC}: Synaptic consolidation protecting important weights
    \item \textbf{Multi-Task Readout}: Task-specific readout heads with Ridge regression
\end{enumerate}

Our key contributions:
\begin{itemize}
    \item Diagnosis of the shared-readout failure mode (14\% acc on Permuted-MNIST $\rightarrow$ 90.6\% with Multi-Task Readout)
    \item Surprise mechanism analysis: demonstrates antagonistic interaction with EWC
    \item Multi-Task Readout architecture that eliminates inter-task interference
    \item State-of-the-art continual learning results on standard benchmarks
\end{itemize}

%--------------------------------------------------
\section{Architecture}
%--------------------------------------------------

\subsection{Liquid Cell (LTC/CfC)}

The core temporal processing unit follows the closed-form continuous-time network:
\begin{equation}
    \frac{dx}{dt} = -\frac{x}{\tau} + f(x, u) \cdot (W_{\text{in}} \cdot u + W_{\text{rec}} \cdot x)
\end{equation}
where $\tau$ is an input-dependent time constant, learned via a small network.
This allows adaptive temporal processing --- fast dynamics for rapidly-changing inputs, slow dynamics for stable patterns.

\subsection{Local Learner (Readout)}

The readout layer uses local learning rules:
\begin{itemize}
    \item \textbf{Delta rule}: $\Delta W = \eta \cdot \varepsilon \cdot x$
    \item \textbf{Oja's rule}: Stabilizes Hebbian learning
    \item \textbf{EWC protection}: Weights are protected proportional to their importance $\Omega$
\end{itemize}

\subsection{Multi-Task Readout}

We identify the \textbf{shared-readout failure mode}: when multiple tasks share a single readout head, they compete for the same weights, leading to catastrophic interference even with EWC.
Our solution: \textbf{Multi-Task Readout} --- each task has its own $W_{\text{out}}^{(t)}$, $b_{\text{out}}^{(t)}$, trained via Ridge regression (closed-form):
\begin{equation}
    W^{(t)} = (X^\top X + \alpha I)^{-1} X^\top Y
\end{equation}
where $X$ are reservoir states and $Y$ is the one-hot encoded target matrix for task $t$.

\subsection{Surprise Mechanism}

We tested two surprise modes:
\begin{itemize}
    \item \textbf{omega mode}: Surprise decays importance weights $\Omega$, weakening consolidation
    \item \textbf{lr mode}: Surprise modulates learning rate directly
\end{itemize}

Finding: \textbf{Surprise is detrimental without meta-learning}. All experiments use surprise\_gain=0.

\section{Discussion}
%--------------------------------------------------

\subsection{Key Insights}

\begin{enumerate}
    \item \textbf{Shared readouts fail catastrophically}: 14\% acc on Permuted-MNIST confirms that a single readout cannot serve multiple tasks, even with EWC. Task-specific heads are necessary.
    \item \textbf{Surprise is harmful}: The surprise mechanism amplifies learning rate when error is high (typically at task boundaries), causing overshoot. Disabling surprise improves accuracy from 66\% to 81\%.
    \item \textbf{Ridge regression outperforms SGD}: Closed-form Ridge regression on reservoir states achieves 90.6\% vs 11\% with online SGD, demonstrating the importance of readout training methodology.
    \item \textbf{Scaling is stable but weak}: $\alpha=+0.056$ indicates the architecture does not suffer from negative scaling, but benefits from increased capacity are modest.
\end{enumerate}

\subsection{Limitations}

\begin{itemize}
    \item \textbf{Local minima in EWC-only}: The best configuration uses EWC without surprise or Oja plasticity, suggesting the full architecture is not yet optimal.
    \item \textbf{Readout bottleneck}: Multi-Task Readout requires storing separate weights per task, which is memory-intensive for 100+ tasks.
    \item \textbf{No language benchmarks}: The architecture has not been tested on sequential language tasks or dialogue.
\end{itemize}

\subsection{Relation to Literature}

\begin{itemize}
    \item \textbf{EWC} \cite{kirkpatrick2017overcoming}: Our work extends EWC with task-specific readout heads.
    \item \textbf{Liquid Networks} \cite{hasani2022liquid,chahine2023robust}: We add local plasticity and multi-task readout to LTC/CfC.
    \item \textbf{Task-specific heads}: Common in multi-task learning but underexplored in continual learning with liquid networks.
    \item \textbf{Scaling laws}: Following Kaplan et al.\ \cite{kaplan2020scaling}, we report $\alpha$ honestly.
\end{itemize}

\subsection{Future Work}

\begin{enumerate}
    \item \textbf{Redesign surprise}: Decouple surprise from EWC; design surprise that detects regime changes (not just high error)
    \item \textbf{Online Ridge}: Incremental Ridge regression for streaming settings
    \item \textbf{Task-free continual learning}: Extend to unknown task boundaries
    \item \textbf{Language tasks}: Test on sequential text classification or dialogue
    \item \textbf{Theoretical analysis}: Why does liquid + local plasticity + task-specific readout prevent forgetting?
\end{enumerate}

%--------------------------------------------------
\section{Conclusion}
%--------------------------------------------------

VISÃO demonstrates that liquid neural dynamics + local plasticity + Multi-Task Readout achieves strong continual learning: 81\% accuracy on Split-MNIST with 1\% forgetting, and 90.6\% on Permuted-MNIST.

The key lessons:
\begin{itemize}
    \item \textbf{Task-specific heads are essential}: Shared readouts fail catastrophically in multi-task settings
    \item \textbf{Simplicity wins}: EWC-only outperforms the full architecture, suggesting the additional mechanisms (surprise, Oja) need redesign
    \item \textbf{Be honest about failures}: Reporting the surprise mechanism's harm and the shared-readout failure provides value to the community
\end{itemize}

Future work must balance plasticity and stability while maintaining the capacity to learn complex tasks.
